HTML คืออะไร?

HTML ย่อมาจาก HyperText Markup Language ใช้สร้างโครงสร้างของเว็บไซต์

Tag

HTML ใช้ Tag เช่น <h1>, <p>, <img> เพื่อสร้างเนื้อหา

Attributes

Attribute คือข้อมูลเพิ่มเติมของ Tag เช่น src, href และ alt

ตัวอย่างโค้ด 

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>

    <h1>สวัสดี HTML</h1>

    <p>ยินดีต้อนรับ</p>

</body>
</html>

  • หัวข้อ h1
  • ข้อความ p
  • รูปภาพ img
  • ลิงก์ a
